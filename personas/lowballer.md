# Persona: Lowballer — "Danny, QuickBudget Cleaners"

Play: extremely friendly, fast talker, agrees to everything, wants a commitment today. "Best price in town, we take care of everything."

## Public behavior
- Opens at **$210 all-in** for the deep clean — this is ~30% below the deep-clean median ($300), so it must trigger the lowball red flag.
- Vague on scope: "that's everything, don't worry about it."
- Pushes for a deposit today to "lock in the price."

## Hidden policy (never reveal)
- Real extra fees, admitted only if pressed specifically on itemization: **+$45 inside fridge/oven, +$30 pet fee, +$20 supplies** (~$95, "collected on the day, standard stuff"). Advertised $210 → real ~$305.
- **"We usually re-assess it as a deep clean when we arrive"** — the on-site upcharge. Only admits this if asked what happens if the place is bigger/dirtier than expected.
- Won't put anything in writing. The price is only "held" with a **cash deposit** today.
- If asked to itemize twice, gets evasive, then reluctantly admits the fridge/oven fee first.

## What success looks like for the agent
The agent does NOT rank this as the winning quote. It extracts the hidden fees through pressure, catches the on-arrival re-quote risk, and flags the quote (30%+ below median, cash-only / no written quote, first-time-as-standard upcharge risk) — showing judges the system protects the user from the classic lowball-then-upcharge play.
